# 🐍 Python Snake Game

A classic Snake Game built with **Python** using the **Turtle graphics library**.

This project was created as a practical Python programming project to explore game logic, object-oriented programming, keyboard controls, collision detection, scoring, and dynamic object movement.

## 🎮 Features

* 🐍 Classic Snake gameplay
* 🍎 Randomly generated food
* 📈 Real-time score tracking
* 🐍 Snake grows after eating food
* 🧱 Wall collision detection
* 💥 Snake self-collision detection
* 🔄 Game-over functionality
* ⌨️ Keyboard-controlled movement

## 🛠️ Technologies Used

* **Python 3**
* **Turtle Graphics**
* Object-Oriented Programming (OOP)

## 📂 Project Structure

```text
Python-Snake-Game/
│
├── main.py          # Main game loop and game logic
├── snake.py         # Snake creation, movement, and growth
├── food.py          # Food generation and positioning
├── scoreboard.py    # Score tracking and game-over display
├── .gitignore       # Files excluded from Git tracking
└── README.md        # Project documentation
```

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Python-Snake-Game.git
```

### 2. Navigate into the project

```bash
cd Python-Snake-Game
```

### 3. Run the game

```bash
python main.py
```
